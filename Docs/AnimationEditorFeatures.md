# ONEngine Animation Editor 仕様・拡張計画

## 1. 概要
本ドキュメントは、ONEngineの汎用アニメーションツール「Animation Editor」の現在の実装仕様（出来ること）と、今後の機能拡張のロードマップをまとめたものです。

このエディタは、Transform（移動・回転・拡大縮小）だけでなく、UIやエフェクトなど、ECSアーキテクチャ上のあらゆるコンポーネントパラメータをタイムラインから統合的に制御し、リッチな演出（カットシーンやボスの攻撃モーションなど）を作成することを目的としています。

## 2. 現在の機能と仕様 (実装済み)

### 2.1. タイムラインの基本操作
*   **直感的なUI**: `ImSequencer` をベースにしたタイムラインGUI。
*   **キーフレーム操作**:
    *   **移動**: タイムライン上のキーフレーム（黄色のダイヤ）をマウスドラッグで移動。自動で時間順にソート。
    *   **追加**: トラック上の空きスペースを**ダブルクリック**、またはホバー中に **'K'キー**。
    *   **削除**: キーフレームを選択して **'X'キー**、または**右クリックメニュー**から `Delete Keyframe`。
*   **Undo / Redo 対応**: トラックの追加・削除、キーフレームの移動・編集など、破壊的な操作は全て `Ctrl+Z` / `Ctrl+Y` の履歴に記録され、安全に試行錯誤が可能。

### 2.2. 対応プロパティとコンポーネント
専用のレジストリ（`g_PropRegistry`）により、以下のプロパティがアニメーション可能です。

*   **Transform**: `position`, `rotation` (Euler), `scale`
*   **Material (Renderer)**: `MeshRenderer` および `SpriteRenderer`
    *   `uvOffset` (テクスチャスクロール)
    *   `uvScale` (タイリング変更)
    *   `uvRotation` (テクスチャ回転)
    *   `color` (ベースカラー。詳細パネルではColorPickerで直感的に編集可能)
*   **DirectionalLight**: `color`, `intensity`
*   **ParticleSystem**:
    *   Main: `startLifetime`, `startSpeed`, `startSize`, `startRotation`, `startColor`, `gravityModifier`
    *   Emission: `enabled` (発生のON/OFF), `rateOverTime` (発生量)
    *   Shape: `radius`, `angle`
*   **C# Script (Variables)**: スクリプトで定義された変数もバインド可能。

### 2.3. アニメーションプレイヤー (AnimationPlayer)
*   エンティティにアタッチして使用。指定された `AnimationClip` を再生。
*   **動的バインド**: `Play()` が呼ばれるタイミングでコンポーネントを再検索するため、実行中に後から追加されたコンポーネント（例：後付けのParticleSystem）も正しくアニメーション可能。

## 3. 今後の拡張アイデア (ロードマップ)

以下の機能を追加することで、よりプロフェッショナルな演出（カットシーン、ボスの複雑なモーションなど）の制作効率が劇的に向上します。

### 3.1. カーブエディタ (Bezier Curve / Easing) 【最優先】
*   **内容**: 現在の `Linear` (直線補間) と `Step` (瞬間変化) に加え、グラフエディタ上でベジェ曲線を操作し、滑らかな加速・減速（Ease-In/Out）を作れるようにする。
*   **効果**: 生き物のしなやかな動きや、タメからの急加速など、**アニメーションの「気持ちよさ」**を表現するために必須。

### 3.2. スクラブ再生 (リアルタイムプレビュー)
*   **内容**: エディタ上でタイムラインの現在位置（シークバー）をドラッグして動かした際、即座に3Dシーン上のモデルやパーティクルが連動して動くようにする。
*   **効果**: 「30フレーム目でどう見えるか」を再生ボタンを押さずに確認できるため、タイミング調整の作業効率が数倍に向上。

### 3.3. アニメーション・イベント (Animation Events)
*   **内容**: タイムライン上の特定フレームに「イベントピン（文字列や関数名）」を配置できる専用トラックを追加する。
*   **効果**: 「剣を振った瞬間にSEを鳴らす」「魔法陣が光った瞬間に当たり判定を出す」など、**プログラムの関数呼び出しを演出のタイミングと完全に同期**させることが可能になる。

### 3.4. 編集の効率化 (複数選択・コピペ)
*   **内容**: ドラッグで複数のキーフレームを囲んで選択し、まとめて移動させたり、`Ctrl+C` / `Ctrl+V` でコピー＆ペーストできるようにする。
*   **効果**: 「点滅」や「往復」など、同じ動きの繰り返しを手作業で打つ手間が省ける。

### 3.5. 逆再生対応
*   **内容**: `AnimationPlayer` の `speed` パラメータにマイナスの値を入れた際、アニメーションが逆再生されるように補間ロジックを対応させる。
*   **効果**: 「攻撃」のモーションを逆再生して「構えに戻る」モーションとして使い回すなど、アセットの再利用性が高まる。
