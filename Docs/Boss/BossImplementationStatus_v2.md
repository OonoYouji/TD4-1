# ボス v2 実装状況チェックリスト

このドキュメントは `BossSpecification_v2.md` に基づき、現在の実装が仕様を満たしているかを検証するためのチェックリストです。

## 1. 基本システム & HP管理
- [x] **常時HP回復**: `HPRegenNode` がフェーズごとに設定された回復量を適用しているか。
- [ ] **フェーズ遷移**: HP閾値（70%, 40%等）で正しく Behavior Tree が切り替わっているか。
- [ ] **演出の連動**: `BossPerformanceDirector` がフェーズ移行時に指定のエフェクトを再生しているか。

## 2. 移動システム
- [x] **ウェイポイント巡回**: `PatrolWaypointsNode` が指定された順序（1 -> 2 -> 3...）で移動しているか。
- [x] **移動中待機**: 移動開始前（`startWaitTime`）と到着後（`endWaitTime`）の待機が機能しているか。
- [x] **押し出し挙動**: 移動中に岩や障害物に衝突しても速度を維持し、対象を押し退けているか（物理挙動の確認）。

## 3. 攻撃アクション

### 攻撃1：ビーム攻撃
- [x] **ターゲット選定**: 援軍の密集地を優先的に狙っているか。
- [x] **予測線表示**: 発射前に `ShowIndicatorNode` による予測線が出ているか。
- [x] **追尾・照射**: 待機中および照射中にターゲットを追尾し、設定された時間照射し続けているか。

### 攻撃2：詰まらせ攻撃（巨大化）
- [x] **範囲判定**: ボス周囲の援軍を正確に検知しているか。
- [x] **巨大化ロジック**: `ScaleUpAreaEntitiesNode` により、援軍のスケールが正しく変更されているか。
- [x] **物理的渋滞**: 巨大化した援軍同士が物理的に衝突し、移動を阻害しているか。

### 攻撃3：爆弾攻撃（回転投擲）
- [x] **回転挙動**: `RotateAndSpawnProjectileNode` により、指定速度で回転しながら発射しているか。
- [x] **射程切り替え**: **fireDistance1 と fireDistance2 を交互に使用しているか**（v2追加仕様）。
- [x] **着弾予兆**: 着弾位置に `TelegraphCircle` が表示されているか。

### 攻撃4：岩持ち上げ
- [x] **岩の確保**: フィールド上のランダムな岩を `PickRandomRockNode` で選択できているか。
- [x] **狙い撃ち**: 援軍が集まっている場所を狙って落としているか。

### 攻撃5：寄せ（竜巻）
- [x] **フィールド配置**: `SpawnVortexFieldNode` により、ボスの周囲に円状に吸い込みフィールドが生成されるか。
- [x] **吸引ロジック**: フィールドに触れた援軍が中心に吸い寄せられ、速度を失っているか。

### 攻撃6：柱落とし
- [x] **連続落下**: **1回のアクションで指定数（dropCount）の柱が落ちるか**（v2追加仕様）。
- [x] **方向性**: プレイヤーがいる方向に沿って、順番に（端から）落ちているか。
- [x] **予兆と落下の連動**: 予兆が表示された後、時間差で柱が降ってくるか。

## 4. 統合・AI
