# ボス演出シーケンス設計仕様書

このドキュメントでは、ボスの主要な3つの演出（開幕、フェーズ遷移、撃破）のトリガーと挙動について定義します。

## 1. 演出の種類とトリガー

| 演出名 | トリガー条件 | AIの状態 | 終了後の挙動 |
| :--- | :--- | :--- | :--- |
| **開幕演出 (Intro)** | ゲーム開始直後 (HP 100%超) | 一時停止 | AI開始、HP減少開始 |
| **フェーズ遷移 (Transition)** | HPが特定の閾値を下回った時 | 一時停止 | AI再開（次のフェーズへ） |
| **撃破演出 (Death)** | HPが 0 になった時 | 永久停止 | ボスエンティティの破棄、クリア判定 |

## 2. 挙動の詳細

### 2.1 開幕演出 (Intro)
*   **目的**: プレイヤーにボスの登場を印象付ける。
*   **挙動**: `BossPerformanceDirector` が開始時に `hpThreshold >= 1.0` の演出を検索し、存在すれば実行。その間、ボスは無敵状態（オプション）となり、AIは停止する。

### 2.2 フェーズ遷移演出 (Transition)
*   **目的**: ボスの攻撃が激化することを視覚的に伝える。
*   **挙動**: HPが 70% や 30% などの閾値をまたいだ瞬間に発動。ボスの足を止め、咆哮や爆発などのエフェクトを表示。完了後、新しい行動パターンが開始される。

### 2.3 撃破演出 (Death)
*   **目的**: 勝利の達成感を与える。
*   **挙動**: 
    1.  `HP.cs` が 0 を検知するが、即座には破棄しない。
    2.  `BossPerformanceDirector` が撃破演出用プレハブを生成。
    3.  演出中、ボスは全ての衝突判定を無効化し、AIを停止。
    4.  演出プレハブの消滅後、ボスエンティティ自身を破棄する。

## 3. 実装上の注意点
*   **AIの一時停止**: `AgentIntentComponent.isPaused = true` を使用して、物理挙動とBTの両方を止める。
*   **HPの同期**: 演出プレハブ側に `TimedDestruction` を持たせ、その消滅を `Director` が検知することで「演出終了」とみなす。
*   **撃破時の破棄管理**: `HP.cs` に `disableAutoDestruction` フラグを追加し、ボスのみ演出完了まで生存し続けるようにする。
