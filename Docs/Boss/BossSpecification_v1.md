# ボスキャラクター仕様書 (v1)

このドキュメントは「ボス仕様書v1.pdf」を解析し、実装向けに詳細をまとめたものです。

## 1. 概要
*   **当たり判定**: 正方形の衝突判定を持つ。
*   **HPシステム**: 
    *   HPは常に回復し続ける仕様。
    *   常に回復しているため、プレイヤーが一定以上の火力を出さないと倒せないバランスを想定。
*   **フェーズ構成**: 
    *   HPが一定数減るごとにフェーズが進行する。
    *   フェーズ移行に伴い、各種パラメータ（移動速度、攻撃頻度等）や使用する攻撃の種類が変化する。
*   **行動設計**: 
    *   「移動」を行動パターンの一つとして扱い、他の攻撃パターンと並列・連続して実行可能な設計。
    *   ※行動パターンを複数同時に実行できる構造（並列実行）を推奨。

## 2. 基本パラメータ (フェーズごとに設定)
*   **共通**: HP、HP回復量（1秒あたりの回復値）。
*   **移動**: 移動位置の数、移動先座標リスト、移動開始までの待機秒数、移動速度。

## 3. 行動・攻撃詳細

### A. 移動フェーズ
*   **挙動**: 設定された移動ポイント（1番〜4番など）を番号順に巡回する。
*   **意図**: プレイヤーがボスの次の位置を予測できるようにするため。
*   **障害物対応**: 移動中にフィールド上の岩に衝突した場合、岩の質量に関わらずボスの速度を維持して移動し、岩を押し退ける。

### B. 攻撃1：ビーム攻撃
*   **ターゲット**: 援軍が最も集まっている場所を常に追従して狙う。
*   **予兆演出**: 照射前の待機時間中に「予測線（レーザーガイド）」を表示する。
*   **発動**: 待機終了後、一定時間（発射継続時間）ビームを出し続ける。

### C. 攻撃2：詰まらせ攻撃
*   **効果**: ボスを中心とした特定の円範囲内にいる援軍を巨大化させる。
*   **ギミック意図**: 援軍を大きくすることで「進路の渋滞」を引き起こす。
*   **プレイヤーへの教育**: 渋滞がデメリットであることを気づかせるためのミスディレクション（誘導）として機能させる。

### D. 攻撃3：爆弾攻撃
*   **挙動**: ボスが回転しながら周囲に爆弾を投擲する。
*   **発射ロジック**: 
    *   発射間隔ごとに爆弾を投げる。
    *   発射ごとに「遠距離」と「近距離」の目標距離を切り替え、フィールド全体をまんべんなく攻撃する。
*   **終了条件**: 指定された回転数に到達すると次の行動へ移行。
*   **演出**: 着弾位置に範囲攻撃が発生（落下時間はパラメータで調整可能）。

### E. 攻撃4：岩持ち上げ攻撃
*   **フロー**: 
    1. フィールド上のランダムな岩を持ち上げる。
    2. 援軍が集まっている場所に狙いを定める。
    3. 落下予測地点を表示した後、岩を落とす。
*   **特殊仕様**: 攻撃間隔をマイナス値に設定することで、一つの岩を落としている最中に次の岩を持ち上げ始める「連続攻撃」を可能にする。

### F. 攻撃5：寄せ攻撃（吸引竜巻）
*   **挙動**: ボスの周囲に複数の吸引フィールド（竜巻イメージ）を等間隔で発生させる。
*   **効果**: 範囲内の援軍を中心部へ吸い寄せる。吸い込まれた援軍は本来の移動速度を失う。

## 4. エンジニア向け実装メモ
*   **データ構造**: 各フェーズのパラメータは外部JSONファイルから読み込み、動的に切り替えられるようにする。
*   **予兆システム**: 予測線や落下範囲円など、プレイヤーが回避行動を取れるための視覚的フィードバックをコンポーネント化する。
*   **複数行動の並列化**: ビヘイビアツリーにおいて、移動を行いながら攻撃アクションを選択・実行できる構造（Parallelノードなど）を検討する。
