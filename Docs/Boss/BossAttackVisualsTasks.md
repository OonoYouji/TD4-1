本ドキュメントは、ボスの各アクションにおいて、プリミティブなメッシュ（Cube, Sphere, Cylinder等）の表示とトランスフォーム操作（拡大・移動）による視覚化、およびダメージ判定の実装計画をまとめたものです。

## 1. 共通基盤タスク (前提タスク)
各攻撃を作り込む前に、以下の基盤を整える。

- [ ] **汎用ダメージ判定スクリプト (`DamageTrigger.cs`) の実装**
  - Trigger（Collider）に触れたエンティティ（Player/Enemy等）を検知し、指定されたダメージや効果を与える。
  - プロパティ: `damage`, `interval` (持続ダメージ用), `targetTag` (判定対象)。
- [ ] **演出用エンティティ生成の簡易化**
  - C#からプリミティブメッシュ（`cube.obj`, `cylinder.obj`等）を素早くスポーンさせるヘルパー、または共通プレハブを用意する。

## 2. 各攻撃の個別タスク (簡易メッシュ版)

### 2.1 ビーム攻撃 (`Attack_Beam`)
**概要**: ボスから直線的に伸びる細長いメッシュを表示し、判定を発生させる。
- [ ] **ビジュアル**: `Cylinder` メッシュをターゲット方向に向け、長さに応じて Z スケールを伸ばす。
- [ ] **当たり判定**: ビーム用メッシュに `DamageTrigger` をアタッチし、持続ダメージを設定。

### 2.2 回転爆弾バラマキ (`Attack_Bomb`)
**概要**: ボスから放出される小さな球体を表示し、着弾時に一瞬大きくして爆発を表現する。
- [ ] **ビジュアル**: `Sphere` メッシュを弾として飛ばす。寿命切れ（着弾）時にスケールを 1.0 -> 5.0 に一瞬で拡大し、消去する。
- [ ] **当たり判定**: 拡大した瞬間に `SphereCollider` の Trigger を一瞬有効化し、範囲ダメージを与える。

### 2.3 ジャイアント攻撃/周囲拡大 (`Attack_Giant`)
**概要**: ボス足元から広がる円盤状のメッシュで範囲を表示し、判定を発生させる。
- [ ] **ビジュアル**: 足元に配置した薄い `Cylinder` を、最大半径まで徐々にスケールアップさせる。
- [ ] **当たり判定**: スケールに合わせて `SphereCollider` の半径を同期させ、プレイヤーにノックバックを与える。

### 2.4 岩落とし (`Attack_Rock`)
**概要**: 上空から `Cube` メッシュをターゲット地点に落下させ、着弾判定を出す。
- [ ] **ビジュアル**: 頭上に `Cube` を生成。ターゲット座標に向かって Y 軸方向に直線移動させる。
- [ ] **当たり判定**: 着弾時に `BoxCollider` をアクティブにし、大ダメージとスタン（移動停止）を与える。

### 2.5 吸引ヴォルテックス (`Attack_Vortex`)
**概要**: プレイヤーを引き寄せる判定を持つ、回転する簡易メッシュを表示する。
- [ ] **ビジュアル**: ターゲット地点に `Cylinder` を配置。Y軸を中心に回転（Rotate）させ、吸い込み範囲を可視化。
- [ ] **当たり判定**: 範囲内にいる間、エンティティの座標を中心に向かって `lerp` や `velocity` で引き寄せる。
