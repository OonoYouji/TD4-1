# ボス演出（パフォーマンス）作成ガイド

このドキュメントでは、ボスの開幕演出やフェーズ遷移演出を新規に作成する手順を解説します。
本システムでは、**「演出 ＝ 1つのプレハブ」** として作成し、それを管理スクリプトが呼び出す形式をとっています。

## 1. 演出プレハブの作成

演出の本体となるプレハブを作成し、以下のコンポーネントを構成します。

### 必須コンポーネント
1.  **`TimedDestruction.cs`**:
    *   **役割**: 演出の「長さ（秒数）」を決定します。
    *   **設定**: `lifeTime` に演出を継続させたい秒数（例: 3.0）を入力。
    *   **重要**: この秒数が経過してプレハブが消滅すると、ボスのAIが自動的に再開されます。

2.  **`BossPerformanceTrigger.cs`**:
    *   **役割**: 演出開始時の単発アクション（カメラ揺らし等）を実行します。
    *   **プロパティ**:
        *   `shakeCamera`: ONにすると画面が揺れます。
        *   `soundPath`: 再生したいSEのパスを指定。
        *   `effectName`: 別途 `FrameEvent` でエフェクトを出したい場合に指定。

### 任意コンポーネント（見た目・音）
*   **`ParticleSystem`**: 咆哮のオーラや衝撃波など。
*   **`AudioSource`**: 演出中に流す音。

---

## 2. ボスへの登録

作成したプレハブをボスに紐付けます。

1.  ボス（Boss）のエンティティに **`BossPerformanceDirector.cs`** をアタッチします。
2.  `performances` リストに新しい要素を追加します。
3.  **プロパティの設定**:
    *   **`hpThreshold`**: 演出を開始するHP割合。
        *   `1.1` など 1.0 以上にすると、**開幕演出** として動作します。
        *   `0.7` にすると、HPが70%を切った瞬間に **フェーズ遷移演出** が走ります。
    *   **`prefabPath`**: 作成した演出プレハブのパスを入力。
        *   例: `Assets/Prefabs/BossRoarPerformance.prefab`

---

## 3. システムの仕組み（内部挙動）

1.  **監視**: `BossPerformanceDirector` が毎フレームボスのHPを監視。
2.  **発火**: 閾値を下回ると、指定されたプレハブを生成し、**ボスのAI（Behavior Tree）を一時停止**。
3.  **実行**: プレハブが生成され、`BossPerformanceTrigger` がカメラ等を揺らす。
4.  **終了**: `TimedDestruction` によりプレハブが消滅。
5.  **再開**: `BossPerformanceDirector` がプレハブの消滅を検知し、**ボスのAIを再開**。

## 4. 作成のコツ
*   **AIをいじらない**: 演出の長さを変えたい場合は、`TimedDestruction` の秒数を変えるだけです。AIのノードを修正する必要はありません。
*   **プレハブ単体テスト**: 演出を確認したい時は、そのプレハブを直接シーンに置くだけで（カメラシェイクやSEを含めて）再生確認が可能です。
