# ボスキャラクター仕様書 (v2) - [更新版]

「ボス仕様書v2.pdf」の最新更新に基づき、実装・設計情報を更新しました。

---

## 1. 基本パラメータと挙動
*   **HPシステム**: 
    *   最大HP: 1200
    *   自動回復: 秒間 5 HP（プレイヤーの攻撃が止まると回復が追いつく設計）
*   **フェーズ構成**: HPの残量によって **4つのフェーズ（Intro + 3段階）** に移行する。

| フェーズ | HP範囲 | 状態・主な行動 |
| :--- | :--- | :--- |
| **Intro** | 100% 超 | 無敵・静止状態（演出待ち） |
| **第1フェーズ** | 70% ～ 100% | 巡回移動（地点A-B）、爆弾投擲（弾道攻撃） |
| **第2フェーズ** | 40% ～ 70% | プレイヤー追従移動、ビーム放射（直線範囲攻撃） |
| **第3フェーズ** | 0% ～ 40% | フィールド中央へ移動、ボルテックス（全方位・引き寄せ・ダメージ増大） |

---

## 2. 攻撃パターンの詳細更新
### 2.1 爆弾投擲 (Phase 1)
*   **更新**: 爆弾の爆発半径が 5.0 -> 7.0 へ拡大。

### 2.2 ビーム放射 (Phase 2)
*   **属性**: 連続ヒット判定に加え、ヒット時にプレイヤーの移動速度を 20% 低下させるデバフを追加。

### 2.3 ボルテックス (Phase 3)
*   **引き寄せロジック**: ボスとの距離が近いほど、引き寄せの力が強くなる（二次関数的な減衰）。
*   **ダメージ**: 中心部（半径3.0以内）にいるプレイヤーには継続的に大ダメージを与える。
*   **フィニッシュ**: 演出終了時の大爆発はフィールド全域（回避不可、遮蔽物でのみ軽減可能）。

---

## 3. 追加仕様：憤怒状態 (Enrage)
*   **トリガー**: 戦闘開始から 300秒（5分）が経過した場合。
*   **効果**:
    *   移動速度 1.5倍
    *   攻撃間隔 50% 短縮（連射化）
    *   全身が赤く発光するエフェクトを強制適用。

---

## 4. 実装のポイント
*   **BT連携**: `BossMain.json` の `BossPhaseDecorator` の閾値を **40% / 70%** に修正する必要がある。
*   **タイマー監視**: `Enrage` 状態の実装のため、`BossAI.cs` 等で戦闘開始からの累積時間を計測し、Blackboard の `IsEnraged` フラグを立てるロジックが必要。
*   **デバフ実装**: ビームヒット時の移動速度低下（Slow）を `MovementSystem` またはプレイヤー側のスクリプトに連携する。

---

## 5. 変更点 (v2 初版からの主な更新)
*   **フェーズしきい値の変更**: Phase 3 の開始ラインを 30% -> **40%** に引き上げ。
*   **Enrage（時間切れ）要素の追加**: 5分経過での狂暴化。
*   **攻撃の細部調整**: 爆弾の範囲拡大、ビームへのスロウ効果追加、ボルテックスの距離減衰ロジック。
