# ボスキャラクター仕様書 (v2) - [修正版]

「ボス仕様書v2.pdf」に基づき、実装・設計情報を整理しました。

---

## 1. 基本パラメータと挙動
*   **HPシステム**: 
    *   最大HP: 1200
    *   自動回復: 秒間 5 HP（プレイヤーの攻撃が止まると回復が追いつく設計）
*   **フェーズ構成**: HPの残量によって **4つのフェーズ（Intro + 3段階）** に移行する。

| フェーズ | HP範囲 | 状態・主な行動 |
| :--- | :--- | :--- |
| **Intro** | 100% 超 | 無敵・静止状態（演出待ち） |
| **第1フェーズ** | 70% ～ 100% | 巡回移動（地点A-B）、爆弾投擲（弾道攻撃） |
| **第2フェーズ** | 40% ～ 70% | プレイヤー追従移動、ビーム放射（直線範囲攻撃） |
| **第3フェーズ** | 0% ～ 40% | フィールド中央へ移動、ボルテックス（全方位・引き寄せ） |

---

## 2. 攻撃パターンの詳細
### 2.1 爆弾投擲 (Phase 1)
*   **更新**: 爆弾の爆発半径を **7.0** へ拡大。
*   **挙動**: インジケーター表示後に着弾、広範囲にダメージを与える。

### 2.2 ビーム放射 (Phase 2)
*   **属性**: 連続ヒット判定に加え、ヒット時にプレイヤーの **移動速度を 20% 低下させるデバフ** を追加。
*   **挙動**: ガイドライン表示後に照射開始、プレイヤーをゆっくり追従する。

### 2.3 ボルテックス (Phase 3)
*   **吸引**: ボスとの距離が近いほど、引き寄せの力が強くなる（距離の2乗に反比例）。
*   **ダメージ**: 中心部（半径3.0以内）にいるプレイヤーには継続的に大ダメージを与える。
*   **フィニッシュ**: 演出終了時に大爆発を起こす。

---

## 3. 実装のポイント
*   **BT連携**: `BossMain.json` の `BossPhaseDecorator` の閾値を **40% / 70%** に設定済み。
*   **演出の同期**: 
    *   `startAnim` / `endAnim` を活用し、攻撃や移動の開始・終了タイミングを自動制御。
*   **デバフ実装**: ビームヒット時の移動速度低下（Slow）を `Player.cs` の `ApplySlow` で処理。

---

## 4. 変更点 (v1 からの主な更新)
*   **フェーズしきい値の変更**: Phase 3 の開始ラインを 30% -> **40%** に引き上げ。
*   **攻撃の細部調整**: 爆弾の範囲拡大、ビームへのスロウ効果追加、ボルテックスの強力な吸引・中心ダメージ。
