# ボス仕様書 v2

## 1. 概要
* **当たり判定**: 正方形
* **HP仕様**: 常に回復し続ける。ただし、常に回復だと普通に攻撃する意味がなくなるため調整が必要。
* **フェーズ進行**: HPが一定数減るごとにフェーズが進む形式。
* **フェーズごとの変化**: フェーズが進むとパラメーターや攻撃の種類が変化する。
* **行動パターン**: 移動も行動パターンの1つとして組み込む。また、行動パターンを複数実行できるようにする。

---

## 2. フェーズごとの使用攻撃
* **1フェーズ目**: ビーム、でっかくする攻撃（詰まらせ攻撃）、岩持ち上げ
* **2フェーズ目以降**: 残り全部の攻撃を使用

**移動の挙動詳細:**
* 移動までの秒数が経過したら移動を開始する。
* 移動位置に到達したら攻撃パターンに移行する。
* 動きを予測できるようにするため、移動位置の数字順に周る。
* 移動中に岩にぶつかった場合、岩の質量に関わらず速度を維持して移動する。岩は押し戻しの挙動を取る。

## 4. 攻撃詳細

### 攻撃1：ビーム攻撃
* **イメージ**: ビームやレーザー
* **挙動**:
    * 援軍が集まっている場所を狙って攻撃する。
    * 待機時間中に予測線が出る。
    * 待機時間中も常に狙う場所は更新され続ける。
    * 待機時間が終わるとビームを発射し、発射継続時間の間は発射し続ける。

### 攻撃2：詰まらせ攻撃
* **挙動**:
    * 予備動作が終わったら発動する。
    * ボスを中心とした円の内側に援軍が入ると、範囲内の援軍が大きくなる。
    * これにより渋滞が起きて攻撃しづらくなる。プレイヤーに渋滞を気づかせつつ、それがデメリットであるというミスディレクションを発生させる狙いがある。

### 攻撃3：爆弾攻撃
* **挙動**:
    * 爆弾を山なりの軌道で投擲し、着弾位置に範囲攻撃を行う。
    * ボスが回転しながら、発射間隔ごとに爆弾を投擲する。
    * 発射するごとに2つの発射距離を切り替え、まんべんなく攻撃する。
    * 爆弾は設定した秒数をかけて落下する。
    * 指定したボスの回転回数に達したら次の行動へ移行する。
    * 演出として、落下予測位置を出したい。

### 攻撃4：岩持ち上げ攻撃
* **挙動**:
    * ランダムなフィールド上の岩を持ち上げる。
    * 援軍が集まっている場所へ狙いを定める。
    * 岩を落とす。

### 攻撃5：寄せ攻撃
* **イメージ**: 竜巻のようなイメージ
* **挙動**:
    * フィールドの個数分、等間隔で設定した半径上に出現する。
    * 設定した半径のフィールドに援軍が触れると、円の中心に吸い込まれる。
    * 吸い込まれている最中の援軍は、もともとのスピードを失う。
