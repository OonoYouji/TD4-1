## フェーズ 1: 基盤システムと共通機能
ボスの基本生命維持と、攻撃の「予兆」を表示するための共通機能を構築します。

- [x] **HP・フェーズ管理の実装**
    - [x] `CurrentHP` を監視し、BTの実行ブランチを切り替える `BossPhaseDecorator` の作成。
    - [x] ダメージ受容と Blackboard への HP 反映ロジックの構築。
- [x] **予兆・視覚フィードバックシステムの構築** (C++/C#連携)
    - [x] 直線（ビーム用）、円（落下・範囲用）などの予兆ガイドを表示する簡易スクリプト/コンポーネントの作成。
    - [x] `InvokeEventNode` や `ShowIndicatorNode` を介してこれらの予兆を AI から制御できるようにする。

## フェーズ 2: 移動と物理インタラクション

- [x] **巡回移動のブラッシュアップ**
    - [x] 到着時に一定時間待機する設定項目の追加。
    - [x] 進行方向へのスムーズな回転制御の実装。
- [x] **障害物押し退け機能 (`PhysicsPushService`)**
    - [x] 移動中、進行方向にある「岩（Rock）」タグのオブジェクトを自動的に検知し、物理的に押し出すロジックの実装。

## フェーズ 3: 攻撃アクションの個別実装
各攻撃パターンを独立した BT ノードとして実装します。

- [x] **攻撃 1: ビーム攻撃**
    - [x] `FireBeamNode`: 実際にダメージ判定を持つビームを照射する演出・ロジックの実装。
    - [x] メッシュベースの予兆表示システム（`TelegraphLine.prefab`）との連動。
- [ ] **攻撃 2: 詰まらせ攻撃 (巨大化)**
    - [ ] `ScaleUpAreaEntitiesNode`: 範囲内の援軍ユニットのスケールを変更し、当たり判定を肥大化させる。
- [ ] **攻撃 3: 爆弾攻撃 (回転投擲)**
    - [ ] `RotateAndSpawnProjectileNode`: ボスを回転させながら、近距離・遠距離を交互に狙って爆弾を生成する。
- [ ] **攻撃 4: 岩持ち上げ攻撃**
    - [ ] `PickRandomRockNode`: ステージ上の岩を特定。
    - [ ] `DropObjectAtTargetNode`: ターゲット位置への落下物理挙動の実装。
- [ ] **攻撃 5: 寄せ攻撃 (吸引)**
    - [ ] `SpawnVortexFieldNode`: 指定地点に吸引力を発生させるフィールドを生成する。
