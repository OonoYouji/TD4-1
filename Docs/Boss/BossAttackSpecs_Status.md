# ボス攻撃仕様：現状の認識まとめ

仕様書 v2 と現在のコード実装状況に基づいた、各攻撃の挙動およびパラメータの認識です。

---

## 1. ビーム攻撃 (Attack_Beam)
*   **イメージ**: 高火力の直線レーザー。
*   **挙動**:
    1.  **ターゲット選定**: 援軍が最も密集している座標（BlackboardのTargetPosition）を狙う。
    2.  **予兆**: 予測線（TelegraphLine）を表示。待機時間中もターゲットを追尾し続ける。
    3.  **発射**: 一定時間、ビームを照射。照射中も低速でターゲットを追尾する。
*   **主要パラメータ**:
    *   待機時間 (telegraphDuration): 1.5s
    *   発射継続時間 (duration): 2.0s
    *   ダメージ (damage): 50
    *   追尾速度 (trackingRotationSpeed): 2.0

## 2. 詰まらせ攻撃 (Attack_Giant)
*   **イメージ**: 物理的な渋滞を引き起こす妨害工作。
*   **挙動**:
    1.  **予兆**: ボスを中心に赤い円を表示。
    2.  **発動**: 範囲内の援軍（Reinforcement）のスケールを 3倍にする。
    3.  **効果**: 大きくなった援軍同士がぶつかり合い、進軍を妨害する（物理渋滞）。
*   **主要パラメータ**:
    *   攻撃範囲 (effectRadius): 10.0m
    *   スケール倍率 (scaleMultiplier): 3.0
    *   持続時間 (duration): 演出および物理効果の持続

## 3. 爆弾攻撃 (Attack_Bomb)
*   **イメージ**: 広範囲への爆撃。
*   **挙動**:
    1.  **回転**: ボスが高速回転する。
    2.  **投擲**: 回転中に一定間隔で爆弾を山なりに投げる。
    3.  **射程切り替え**: 1発ごとに「近距離(10m)」と「遠距離(22m)」を交互に切り替える（v2修正点）。
    4.  **着弾**: 地面に予兆円が出た後、爆弾が落下して範囲ダメージ。
*   **主要パラメータ**:
    *   回転速度 (rotationSpeed): 720 deg/s
    *   発射間隔 (fireInterval): 0.15s
    *   射程1 (fireDistance1): 10.0m
    *   射程2 (fireDistance2): 22.0m

## 4. 岩持ち上げ攻撃 (Attack_Rock)
*   **イメージ**: フィールド上のオブジェクトを利用した投擲。
*   **挙動**:
    1.  **選択**: フィールド上にある岩（BossRock/Rock）をランダムに 1つ選択。
    2.  **持ち上げ**: 岩をボスの頭上へ浮かび上がらせる。
    3.  **狙い**: 援軍の密集地を狙う。
    4.  **落下**: 岩を高速でターゲット地点へ叩きつける。
*   **主要パラメータ**:
    *   持ち上げる時間 (liftDuration): 約1.5s
    *   狙う時間 (aimDuration): 約1.0s
    *   落下時間 (fallDuration): 高速落下

## 5. 寄せ攻撃 (Attack_Vortex)
*   **イメージ**: ブラックホール/竜巻による吸引。
*   **挙動**:
    1.  **配置**: ボスを中心とした円周上に、複数の吸引フィールド（VortexField）を生成。
    2.  **吸引**: 範囲内の援軍・岩をフィールドの中心へ吸い寄せる。
    3.  **減速**: 吸い寄せられている間、対象の本来の移動速度は無効化（低下）される。
*   **主要パラメータ**:
    *   吸引半径 (suctionRadius): 15.0m
    *   吸引力 (suctionForce): 20.0
    *   フィールド個数: 4〜6個程度（BTで設定）

## 6. 柱落とし (Attack_Pillar)
*   **イメージ**: 進路を塞ぐ巨大な障害物の投下。
*   **挙動**:
    1.  **連続落下**: 指定された本数の柱を順次生成。
    2.  **方向**: ボスから見てプレイヤーがいる方向に沿って、奥に向かって順に落とす。
    3.  **時間差**: 予兆（TelegraphCircle）表示後、一定時間（DelayedAction）を経て上空から柱が落下。
    4.  **遮蔽**: 落ちた柱は 10秒間フィールドに残り、壁として機能する。
*   **主要パラメータ**:
    *   落下数 (dropCount): 5本
    *   落下間隔 (dropInterval): 0.4s
    *   距離間隔 (dropDistanceInterval): 6.0m
    *   予兆時間 (telegraphDuration): 1.5s
